# *Formula 1 Stint and Tyre Analysis*

## Program Overview
This program is made to analyse stints and tyres for any driver across any race of the 2022 – 2025 ground effect era of the formula one world championship. Made using fastf1 to access f1 race data and streamlit to create the user interface <br>
<br>
This program allows the user to select a season, race and driver before displaying data visualisations relating to lap times, tyre stints and pace evolution.
<br>

## Setup
I recommend to use a venv (virtual environment) to run this application. Setup instructions are as follows: <br>
`python3 -m venv .venv` <br>
Then <br>
`source .venv/bin/activate` (for linux) <br>
`.venv\scripts\activate` (for windows) <br>
<br>
### To install necessary dependencies:
`pip install -r requirements.txt`<br>
<br>

## Running the Program
To run the program use a terminal in the root folder: <br>
`streamlit run application.py`
